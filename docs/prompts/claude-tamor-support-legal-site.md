# Claudeへの依頼：TamorのFAQ・利用規約・プライバシーポリシーと公開ページ

Tamor（iPhone/iPad向け宝石収集ゲーム）のFAQ、利用規約、プライバシーポリシーを日本語・英語で作成し、既存のMarcottLabサイトにTamor専用の掲載場所を用意してください。一般的な雛形をそのまま貼らず、アプリの実装と運用に一致する、短く読みやすい文章にしてください。

## 対象と作業範囲

- アプリ：Tamor。SwiftUI＋Metal、iOS 17以降、iPhone/iPad、日本・米国向け。バージョン1.0の公開準備中で、TestFlightでの試遊も予定しています。
- アプリのリポジトリ：https://github.com/sugie/tamor （PR #1はマージ済み）。ローカルが使える場合は `/Users/tsugie/opt/tamor`。mainの最新実装を読み、本文の事実を照合してください。
- 掲載先：https://marcottlab.com/
- サイトのリポジトリ：https://bitbucket.org/fyhealth/marcottlab-site/src/main/
- 本番は、さくらのクラウドのIaaS上のUbuntuで運用しています。別サービスへの移行や新規ホスティング契約は不要です。
- 今回は文書本文、既存サイトへの掲載実装、テスト、公開手順をレビュー可能な状態まで作成してください。本番へのデプロイ、DNS変更、サービス再起動、メール送信、App Storeの送信はこの依頼に含めません。
- Tamorのゲームコード・課金コードや他アプリの設定は変更しないでください。アプリへ後で設定できる完成URLの一覧を納品してください。

## アプリについて確認済みの仕様

- World 1はルビー＝Glass Trace、サファイア＝クルクルワールド、ダイヤモンド＝Glass Break、黒曜石＝Crusher Roomの4種類。
- 無料は深度1〜3、最大3.00ct。World 1の非消耗型・買い切り商品は深度4〜6への挑戦範囲を解放します。日本400円・米国1.99ドルで設定済みですが、利用者が実際に支払う価格はストア表示を優先し、規約に恒久固定しないでください。
- 購入後も前深度のクリア等が必要です。最大20.00ctには深度6で同じ宝石・同じルール版のS評価3連続などの技能条件があります。20ctの宝石そのものを販売する商品ではありません。
- 宝石・ctはゲーム内データと尺度で、現物の宝石、所有権証明、金融商品、換金可能資産ではありません。報酬は技能評価に基づき、ランダム抽選による販売はありません。
- 体力制限・サブスクリプションはありません。World 2はComing soon表示だけで、World 1購入特典に含まれません。提供日を約束しないでください。
- Crusherは10秒、1枚3タップ。弱点への命中は破壊した板の得点へ加算されます。旧草稿の「5枚ごとの連続報酬」と混ぜないでください。
- 最大の宝石をリングに表示し、小さい宝石も宝石箱に残ります。旧コレクションや保存移行の扱いは最新コードと照合してください。
- 初回版は端末内JSON保存のみ。CloudKit／iCloud同期は利用しません。ソースが残っていてもビルド対象から除外され、将来機能です。
- 設定にJSONの書き出し・取り込みがあります。取り込み条件はコレクションが空のとき。削除・機種変更前の書き出しと、書き出したファイルを自分で保管する必要を説明してください。Appleの端末バックアップによる復旧を保証しないでください。
- 購入復元はWorld 1の解放権利が対象で、宝石・成績・プレイ履歴の復元とは別です。同じApple Account等の条件はApple/RevenueCatの最新公式説明で確認してください。
- アプリ独自のユーザー登録やログイン、ユーザー間交流、独自の共有サーバーはありません。購入はAppleのアプリ内課金とRevenueCat（実装時点SDK 5.90.2）を使用します。
- 実購入・復元の試験、外部TestFlight配布、本番リリースの完了を、この依頼だけから推測しないでください。TestFlightの試用購入と本番課金を区別してください。

## 必須の内容

### FAQ

初心者が読めるQ&A形式で、遊び始め方、4つのゲーム、深度の解放、無料範囲、買い切りの内容、購入しても宝石が直接増えない理由、20ct条件、小さい宝石の保持、購入復元、購入を認識しない時、ネット接続の要否、保存の書き出し・取り込み、機種変更・削除時の注意、World 2、対応端末、発熱・省電力時の描画、問い合わせ方法を扱ってください。操作名は日英の実UIと一致させてください。

TestFlight向けの案内を付ける場合は一般公開版と区分し、有効期限、フィードバック、テスト中の購入についてAppleの最新公式資料と一致させてください。未発行の招待URLを作らないでください。

### 利用規約

対象アプリ・適用範囲・運営者、利用条件、ゲーム内データ、買い切り商品の範囲、ストア価格・決済、復元・返金の案内、知的財産、合理的な禁止行為、更新・提供中断、端末保存とバックアップ、責任の範囲、規約変更、問い合わせ、準拠法・紛争解決等を検討してください。

Apple標準EULAとの関係を整理し、標準EULAを置き換える独自EULAなのか、補足的な利用条件なのかを提案してください。運営者に無条件で有利な免責、消費者の強行法上の権利を無視した「一切返金不可」等は避けてください。未確認の準拠法・専属管轄・法人情報は勝手に確定せず、確認事項として示してください。法律上の適合性を保証しないでください。

### プライバシーポリシー

アプリ本体、Apple／RevenueCatによる購入関連処理、サポートサイト／問い合わせフォーム、TestFlightのフィードバック・診断を分け、データ項目、目的、処理主体、送信先、保存・削除、問い合わせ方法を具体的に説明してください。

- 「端末保存だから個人情報を一切収集しない」と断定しない。
- RevenueCatの匿名App User ID、購入情報、端末・診断情報等は、実際のSDK設定と最新公式文書で送信有無を確認する。未使用の広告・分析サービスを創作しない。
- Appleが扱う決済情報と、運営者が閲覧できる情報を区別する。カード番号を運営者が取得するかのように書かない。
- サイトの既存プライバシーポリシーと問い合わせフォームを調べる。フォームの名前・メール・本文・IP・User-Agent・不正送信対策データ、機能上のCookie、Ubuntu/Webサーバーのアクセスログ等は実装・設定で確認する。サイトのデータをアプリが直接収集する情報と混同しない。
- さくらのクラウドはサポートサイトの基盤であり、宝石のクラウド保存先であると書かない。リージョン・保存期間・バックアップ期間は未確認なら創作しない。
- 子どもの利用、第三者提供／委託、国外での処理、開示・訂正・削除等について適用範囲を調査し、運用できる内容にする。対応窓口や保存期間を捏造しない。
- App Storeのプライバシー回答に対応するデータ一覧を、公開本文とは別の内部レビュー資料として作る。実際の回答送信は行わない。

## URL・サイト実装の方針

第一案は日本語 `/apps/tamor/`、`/apps/tamor/faq`、`/apps/tamor/terms`、`/apps/tamor/privacy`。英語は既存の `/en` 規約に合わせ、`/en/apps/tamor/` 以下を候補にしてください。これは未作成の提案URLです。既存ルートと衝突する場合は整合する案を示して変更してください。

- 専用の案内トップから3文書と既存の問い合わせ窓口へ移動できるようにする。App Storeリンクは公開状態を確認してから置き、未公開を公開済みとして宣伝しない。
- 既存会社サイトの `/privacy` をTamor専用本文で上書きしない。会社サイトのポリシーとTamorのポリシーを相互に区別して参照する。
- 会社情報は `config/company.php` 等の既存の正本を再利用。連絡先をブラウザのログイン名から推測しない。既存窓口をTamor用にも使えるか確認する。
- Bladeレイアウト、ルーティング、言語切替、canonical、hreflang、レスポンシブ表示、アクセシビリティを既存設計に合わせる。新しいSPAや別CMSは追加しない。
- FAQ・規約・ポリシーはログイン不要のHTTPSページとして掲載する想定。日英で対応するページへ切り替えられること。
- 施行日／更新日は実際の運営者承認・公開日に合わせる。作業日を勝手に施行日にしない。未確定のプレースホルダーをそのまま本番公開しない。
- 本番構成は実際のリポジトリの運用手順を確認する。Dockerファイルがあるだけで本番もDockerと断定しない。Webサーバー、PHP、デプロイ先パス、サービス名を推測して危険なコマンドを実行しない。
