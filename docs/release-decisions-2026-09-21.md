# Tamor 1.0 公開準備の確定事項

2026-09-21。ユーザーのR01〜R08への回答。従来のCloudKit本番化計画より本決定を優先する。

- R01/R02: ChromeのApp Store ConnectとRevenueCatはログイン済み。原則「はたらきろく」と同じAppleチーム・契約・RCアカウントを利用する。AIによる管理画面確認を依頼。初回の接続エラーから復旧し、両管理画面を読み取り確認済み。Tamorの初公開歴・応募資格が確認済みという意味ではない。
- TamorのBundle ID、Appレコード、IAP、Entitlement、Offering、SDKキーはTamorに対応させる。既存アプリの課金をそのまま使わない。RCは同じアカウント内でTamor専用プロジェクトを推奨、管理画面を確認して決める。
- R03: World 1＋既存World 2予告、日本・米国。日本400円の非消耗型深度解放。米国価格は要確認。
- R04: CloudKitは初回版に含めない。端末保存を維持し、同期呼出し・同期UI・iCloud署名・説明を整合させる。購入復元と宝石保存を区別する。クラウドコンテナや既存データは削除しない。
- R05: iPad対応維持で検証・素材作成。未検証の場合は除外の判断を人間へ明示し、無断で対象変更しない。
- R06: アプリ名Tamor、公開バージョン1.0。素材はユーザー申告ではAIで作成した一般的なブリリアンカット等。生成ツール・利用規約・履歴の詳細未確認。AI生成だけで権利保証済みとは扱わない。
- R07/R08: Claude Appへプライバシー・素材権利・審査文書の日英草稿と英語UI実装を依頼。公開・審査・応募の最終送信は別工程。
