本ポリシーは、iOS / iPadOS 向けアプリ「Tamor」(以下「本アプリ」)における利用者情報の取扱いを説明するものです。

## 1. 要約

- 本アプリにアカウント登録・ログインはありません。氏名、メールアドレス、電話番号、位置情報、連絡先、写真、マイク、カメラの情報を求めません。
- 広告は表示せず、広告用SDK・行動解析SDKを組み込んでいません。App Tracking Transparency の対象となる「トラッキング」は行いません。
- ゲームの進行と宝石コレクションは、お使いの端末の中だけに保存されます。開発者のサーバーや iCloud には送信しません。
- アプリ内課金(World 1 深度4〜6の解放)の処理と購入状態の確認のために、Apple の App Store と、課金基盤事業者 RevenueCat, Inc. のサービスを利用します。このとき第3節に記載の情報が RevenueCat に送信されます。

## 2. 端末内に保存される情報(開発者には送信されません)

- 獲得した宝石、各プレイの結果(深度、評価、所要時間、日時)、リングの表示状態: アプリのデータ領域内の JSON ファイル(`Application Support/Tamor/`)
- 中断した Crusher Room の途中経過: 同じフォルダ内のファイル
- 描画品質などの設定、およびアプリがこの端末用に生成したランダムな識別子: アプリの設定領域(UserDefaults)。この識別子は 1.0 では外部へ送信しません。【要確認: Codex の公開用実装で `tamor.deviceID` が外部送信されないことをコードで再確認】

これらはアプリを削除すると端末から消去されます。**1.0 にはクラウドへのバックアップ・同期機能がないため、アプリを削除したり端末を変更したりすると、宝石コレクションは復元できません**(設定画面の「保存データを書き出す」で利用者自身がファイルとして保管することはできます【要確認: この機能を 1.0 に残すか】)。端末全体のバックアップ(iCloud バックアップやコンピュータへのバックアップ)に本アプリのデータが含まれるかどうかは、利用者の端末設定と Apple の仕様によります。

## 3. 外部に送信される情報(アプリ内課金)

購入、購入の復元、購入状態の確認を行うため、本アプリは RevenueCat の SDK(purchases-ios 5.90.2)を利用します。アプリの起動時・復帰時・購入画面の表示時などに、次の情報が RevenueCat のサーバーへ送信されます。

| 情報 | 内容 | 目的 |
| --- | --- | --- |
| 購入情報 | App Store の取引・レシート情報、商品ID、購入・復元の状態 | 購入の検証、解放状態の判定、復元、不正防止 |
| 匿名のアプリユーザーID | RevenueCat SDK が端末上で自動生成するランダムなID。氏名やメール等とは結び付けていません | 購入状態の管理 |
| ベンダー識別子(IDFV) | Apple が同一開発元のアプリに対して端末ごとに発行する識別子。SDK が通信のたびに付加します | 課金基盤の運用(RevenueCat による) |
| 端末・アプリの技術情報 | 機種、OSバージョン、アプリのバージョン・ビルド番号・Bundle ID、優先言語設定、App Store の国/地域コード、SDKバージョン、サンドボックスかどうか等 | 課金基盤の運用、互換性の確保、障害調査 |
| IPアドレス | インターネット通信に伴いサーバー側で受信されます | 通信の成立、セキュリティ |

- 広告識別子(IDFA)は取得・送信しません。メールアドレス等の連絡先情報を RevenueCat に渡すこともありません。
- 開発者は、RevenueCat の管理画面を通じて、上記の匿名IDに紐づく購入状況や集計値を閲覧できます。開発者がこれを特定の個人と結び付けることはありません。
- 決済そのものは Apple が処理します。クレジットカード番号などの支払情報は、開発者にも RevenueCat にも渡りません。Apple による情報の取扱いは Apple のプライバシーポリシーに従います。
- RevenueCat は開発者の委託先(処理者)として情報を取り扱い、データは米国内のサーバーに保存されると同社は説明しています。したがって、上記の情報は日本国外(米国)に移転されます。詳細は RevenueCat のプライバシーポリシー(https://www.revenuecat.com/privacy)をご覧ください。【要確認: RevenueCat との DPA 締結状況。個人情報保護法上の外国にある第三者への提供/委託に関する記載の要否は専門家に確認】

無料の範囲(深度1〜3)だけを遊ぶ場合でも、購入状態を確認するために上記の通信は行われます。【要確認: 実装上、APIキー設定済みの公開ビルドでは起動時に `customerInfo()` と `offerings()` を呼ぶため。】

## 4. 利用目的

取得した情報は、(1) アプリ内課金の提供・検証・復元、(2) 不正利用の防止、(3) 課金に関する障害の調査と問い合わせ対応、(4) 売上の集計 のためにのみ利用します。広告配信、プロファイリング、第三者への販売は行いません。

## 5. 第三者提供

法令に基づく場合を除き、利用者情報を第三者に提供しません。第3節の RevenueCat および Apple への送信は、課金機能の提供に必要な範囲の委託・連携です。

## 6. 保存期間と削除

- 端末内のデータ: アプリを削除するまで。
- RevenueCat 上の購入関連データ: 【要確認: 保存期間の方針】。削除を希望される場合は上記の連絡先までご連絡ください。匿名IDしか保有していないため、ご本人のデータを特定するための情報の提供をお願いすることがあります。【要確認: 削除依頼の受付手順】

## 7. 子どもの利用

本アプリは子ども向けに特化したアプリではありませんが、年齢を問わず個人を特定する情報を求めません。アプリ内課金は、保護者の方が端末の「スクリーンタイム」等で制限できます。【要確認: 年齢区分と Kids カテゴリ非該当の確認】

## 作成メモ(公開版からは削除)

- **Privacy Manifest だけで「収集なし」とは言えない理由:** アプリ本体の `Sources/PrivacyInfo.xcprivacy` は `NSPrivacyCollectedDataTypes` が空ですが、RevenueCat SDK 5.90.2 同梱の Manifest は Purchase History(非リンク・非トラッキング・App Functionality)を宣言しています。さらに SDK のソース(`HTTPClient.swift`、タグ 5.90.2)は全リクエストに IDFV(`X-Apple-Device-Identifier`)と機種・OS・ロケール・ストアフロント等のヘッダを付けており、IDFV は RevenueCat の Manifest にも同社の App Privacy ガイドにも記載がありません。Apple は第三者SDKの収集も開発者の申告責任としています。App Store Connect の申告案は `app-review-notes.md` の「App Privacy 回答案」を参照。
- アプリ本体の Manifest の `NSPrivacyCollectedDataTypes` に Purchase History(と判断により Device ID)を追記するかは Codex/人間側で決定してください(本草稿では Manifest を編集していません)。
