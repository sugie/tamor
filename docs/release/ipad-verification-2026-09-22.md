# iPad実機検証の再開結果（2026-09-22）

## 対象と結果

iPad（第8世代）／iPadOS 26.7（23H24）、Tamor 1.0（5）のローカルDebugビルドを確認。現在の設定はiPhone専用・最低iOS 26.0のため、iPadではiPhone互換モードです。

クレジット不足で停止した直前のテストは、最後のサファイア深度2の再検証まで成功していました。今回、ログを確認して以下を記録し、テスト引数なしの通常起動と画面撮影を完了しました。

- 10:53以降の実機UI検証で、白画面の起動停止は再現していません。
- スクロール修正後の9件実行は **8件成功・1件失敗**。失敗したサファイア深度2のテストを追加修正後に再実行し、**1件成功・失敗0件**（59.651秒、終了コード0）。合算すると日本語6件・英語3件の全項目に成功記録があります。最終ヘルパー修正後に9件を一括再実行したという意味ではありません。
- 日本語：ホーム／宝石箱、サファイア獲得・深度解放・再起動後の保存、ルビー操作、ダイヤモンドのMetal描画、黒曜石のプレイ・報酬、購入画面・設定。
- 英語：ホーム・購入画面・設定、サファイア結果・宝石箱、黒曜石の結果。
- 11:17にdevicectlで既存プロセスを終了して通常起動。起動引数は空、`--ui-test` と `JEWEL_TEST_ID` の指定なし。11:18のXcode実機スクリーンショットで、日本語のホーム、Metalのリング背景、4種類の台座、ゲーム選択ボタンが描画されていることを目視確認しました。
- 通常起動は初期コレクション（0種類・0個）を表示。UIテストの宝石は独立したテスト保存先のため、通常データとは別です。

## 自動テストの修正

`Tests/UI/JewelRingUITests.swift` の操作をiPad互換モードに対応させました。

1. 端末全体の余白を含む領域へのスワイプから、実際のScrollView／CollectionViewへのスワイプに変更。
2. タイトルバーの下に隠れた深度ボタンを、見える位置へ戻してからタップ。
3. スクリーンショットをアプリ領域だけでなく実機画面全体に変更。

今回の再開ではアプリ本体やゲームロジックを追加変更していません。Simulatorの起動・操作、再ビルド、インストール、アーカイブ、アップロード、審査提出は実施していません。

## メモリーと注意点

- スクロール修正後の9件実行：監視対象Xcode／コンパイラRSS最大1,176.1 MiB、スワップ0 MiB。
- 深度2の再実行：RSS最大726.6 MiB、スワップ0 MiB。監視しきい値による中断なし。
- テスト終了時のdevicectl診断収集にはエラーが残っていますが、深度2のテスト自体は `TEST SUCCEEDED`、終了コード0です。
- OS更新・端末初期化・ビルド更新をまたいだため、以前の白画面の根本原因は断定できません。
- 実購入／復元、長時間負荷、他のiPad、iOS 26.0ちょうど、iPhone 17世代の実機は未検証です。UIテスト中は課金通信を無効化しているため、購入画面テストの成功は決済成功を示しません。
- この限定的な検証をもって、iPad全機種の動作保証やストアの対応範囲変更とはしません。
