TAMOR · SHIPATON DEMO VIDEO

デモ動画 撮影手順書

12 mini で 5 分プレイ → 残りは Claude が編集・字幕・書き出し

0. 結論

  • 専用ビルドは不要。 App Store の公開版 1.0 を 12 mini にそのまま使います。TestFlight や開発ビルドは使いません(開発表示が映るのを避けるため)。
  • 役割分担
    あなた(約 15 分)12 mini で画面収録しながら 5 分プレイ。収録ファイルと、書き出した保存データを Mac に送る。
    Claude(a) あなたの収録を切って並べ、英語字幕・タイトル・エンドカードを入れて 2 分未満の mp4 にする。(b) 保存データを Mac のシミュレーターに読み込み、iPhone 17/18 Pro Max の大きな画面で宝石のスポットライト場面を撮る。
  • 「豪華な大きい絵」について。 12 mini(A14)はレイトレーシング非対応で、画面も小さめです。大画面の映像は上の (b) で作ります。iPhone 18 Pro Max(10/18 到着予定)は締切に間に合わないので、今回は使いません。将来のアップデート動画に取っておきます。
時間の目安: 締切は日本時間 10/1 15:45。9/29 中に撮影 → 9/30 午前に編集・アップロード → 9/30 日中に提出を目標にします。

1. 撮影前の準備 約 5 分

画面右上の時計とバッテリーは映って構いません。Apple ID、氏名、メール、購入時のパスワード画面は絶対に映さないでください。

2. 撮る内容(ショットリスト)約 5 分

画面収録は1 本を止めずに続けて撮って構いません。私が切ります。各場面のあいだに 1〜2 秒の「間」を置いてください。動きはゆっくり、指は画面の端に触れないように。

#場面やること長さ
1リング起動直後のリング画面を 3 秒見せる。端末を軽く傾けてリングが動くのを見せる。5 秒
2Glass Break(ダイヤモンド)「Choose Gem & Depth」→ Diamond の Depth 1。赤い点を押してガラスを割り、成功して宝石を獲得するまで。10〜15 秒
3Glass Trace(ルビー)緑の点を指で追う。成功するまで。失敗したら、やり直して成功を撮る。10〜15 秒
4Kurukuru World(サファイア)同じ向きに回る宝石のペアを押していく。クリアまで。10〜15 秒
5Crusher Room(黒曜石)10 秒でガラスを割る。光る弱点を狙う。結果(評価)まで映す。15 秒
6宝石のスポットライトリングに戻り、獲得した宝石をタップ → 中央へ移動 → 指でゆっくり回転 → もう一度タップして戻す。10 秒
7Gem Box「Gem Box」を開いて、集めた宝石を見せて閉じる。5 秒
8深度の一覧「Choose Gem & Depth」で Depth 1〜3 が無料、Depth 4〜6 が鍵つきなのを見せる。5 秒
9購入画面「Unlock World 1 Depths 4–6」を開く。説明文(宝石は付かない、スキル条件は残る)を 3 秒見せて、購入ボタンは押さない。閉じる。5 秒
10購入の復元設定(右上のスライダー)→ Purchases →「Restore Purchases」→ 結果メッセージを見せる。Apple ID の入力画面が出たらキャンセルして、その部分は撮らない。8 秒
ポイント: 失敗の場面は不要です(成功だけ)。宝石が獲得できるまでは、遊びながら何度撮り直しても構いません。全部で 1 分 30 秒ほどの素材が取れれば十分です。
撮らないもの: 購入の支払いシート、Apple ID / パスワード、通知、ホーム画面、設定アプリの画面(言語切替)。World 2 の予告ページも映さないでください(1.0 の購入対象ではないため)。

3. 保存データを書き出す(大画面用) 約 2 分

撮影が終わったら、プレイして貯めた宝石をシミュレーターに移して、大画面で撮り直せるようにします。

  1. Tamor の設定(右上のスライダー)→ 「Export save data(保存データを書き出す)」。
  2. 共有シートで「Mac に AirDrop」。または「ファイルに保存」→ iCloud Drive。
  3. Mac 側の受け取り先: ~/Downloads/ でよい。ファイル名はそのままで構いません。

この保存データには、獲得した宝石と記録だけが入っています。Apple ID や購入情報は入りません。

4. Mac に送る 約 2 分

  1. 画面収録は、写真アプリ → 共有 → AirDrop で Mac に送る(または iCloud 写真の「ファイル」経由)。
  2. Mac 側で、次のフォルダに移す:
    /Users/tsugie/opt/tamor/docs/release/shipaton/raw/
    収録は raw/playthrough.mov、保存データは raw/tamor-save.json(名前は違っていて構いません)。
  3. Claude に「撮った」と伝える。

5. そのあと Claude がすること

  1. あなたの収録から成功場面を切り出し、台本の順に並べる。
  2. 保存データをシミュレーター(iPhone 17/18 Pro Max)に読み込み、宝石のスポットライトや大きな宝石の映像を撮って差し込む。
  3. 英語字幕・タイトル・エンドカード(米国 App Store の URL)を入れて、1 分 45 秒以内の mp4 に書き出す。
  4. あなたが内容を確認したら、YouTube に限定公開でアップロード(アップロードはあなたの YouTube アカウントで行います)。
  5. 動画 URL を Devpost の「Video demo link」に入れる → 規約に同意して Submit(この 2 つはあなたの操作)。
動画に入れない・入れる
入れない: 価格、Apple ID、購入シート、World 2、Neural Engine の話。
入れる: リング、4 つのゲーム、宝石の演出、無料範囲、購入は「深度 4〜6 のアクセスのみ」、購入の復元。

6. うまくいかないとき

症状対処
アプリを英語にできないiPhone の言語を英語に切り替えて撮影し、撮影後に戻す(撮影中の 5 分だけ)。
ゲームの成功が出ないDepth 1 は最も易しい設定です。成功するまで撮り直してください。必要なら私が字幕で「成功場面」を補います。
画面収録に録画ボタンの赤い帯が映る問題ありません。私が上部を切り取ります。
AirDrop が使えない写真アプリから iCloud 経由で Mac の写真アプリに同期 → 書き出し。
時間が足りない#2〜#5 の 4 つのゲームだけを 1 回ずつ撮れば、動画は組み立てられます。
