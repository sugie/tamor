# 光の窓格子

2026-09-20。青灰色の背景に、斜めの窓格子と白い拡散光、小さな暖色光を追加。

窓の桟の間隔はリング座標で横0.32・縦0.44。初期サイズの宝石に明暗の境界が見える密度とした。格子自体は固定し、光の強さを変える広い帯が約39秒の周期でゆっくり往復する。中央に装飾物は追加しない。

## 光の一貫性

表示する背景と屈折先は同じringBackdropを使用。リング背景は線形の光量を返し、通常背景と宝石の最終出力で同じトーンマッピングを適用する。前方の照明窓は同じ桟のパターンを使い、表面の座標と反射方向から映り込む位置を計算。これにより、平らなカット面の中でも窓の線を表示できる。ブラックオニキスは反射のみ。

通常描画は既存の背面深度を用いた2面近似。全反射時の多重光路を厳密に再現するものではない。対応GPUでのRTは既存の最大4回の光線追跡を維持する。iPhone 12 miniは通常描画を使用。

原子表示への拡大に合わせて格子背景を連続的に弱め、構造観察の邪魔を抑える。背景の追加テクスチャ・追加描画パスはない。既存の背景と宝石のフラグメント計算を拡張したためGPU負荷は増える。達成fpsや熱特性の保証はせず、既存の自動画質調整を継続使用する。

## 設定と表示

設定 → 光と描画品質 →「窓からの光をゆっくり動かす」。既定ON、端末のUserDefaultsに保存。OFF・省電力の画質・OSの視差効果を減らす設定では光専用の時計を進めず、現在の照明を静止させる。リングの回転や宝石の操作とは独立。

空き台座の名前と初期案内には暗い背景を敷き、窓の明部でも文字を読みやすくした。取得状態・順番・記録の保存方式は変更していない。

## 検証内容

GPUで実際のMetalパスを実行し、窓に明暗の差があること、宝石内部が背後の背景そのままではないこと、光の時刻が変わると宝石内部にも変化すること、同じ時刻なら同じ描画結果になることを検証する。UIでは光をOFFにして再起動後も保持することと、ダイヤ拡大時の描画を確認する。

実機確認：ケーブル接続のiPhone 12 mini（iOS 26.6.1）で署名付きビルドとインストール・起動に成功。同端末のGPUで上記2件の描画テストが成功。全画面・長時間プレイでのfpsと発熱は未計測。

明るい背景で目立った、フェード完了後の宝石のディザ点残りも修正。可視率0は必ずフラグメントを破棄し、GPUテストで宝石を非表示にした画像が背景のみと完全一致することを確認する。
